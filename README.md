# نظام التذكير الصوتي الذكي | مهام العمل ومواقيت الصلاة 🕌💼

نظام تنبيه صوتي احترافي متكامل لإدارة مهام العمل اليومية ومواقيت الصلاة بدقة فلكية عالية، مزوّد بمحرك نطق صوتي عربي (TTS) وتنبيهات أذان واقعية وإشعارات سطح المكتب لنظام Windows.

---

## ✨ المميزات الرئيسية للنظام

### 1. 🕌 مواقيت الصلاة والأذان التفاعلي
- **حسابات فلكية دقيقة** لجميع الصلوات (الفجر، الشروق، الظهر، العصر، المغرب، العشاء، قيام الليل).
- **طرق حساب متعددة**: الهيئة المصرية العامة للمساحة، جامعة أم القرى، رابطة العالم الإسلامي، دبي، قطر، الكويت، أمريكا الشمالية (ISNA)، وكراتشي.
- **تنبيه صوتي قبل الأذان**: ينبهك قبل 5، 10، أو 15 دقيقة للاستعداد للوضوء وإتمام ما بيدك.
- **أذان صوتي كامل أو تكبيرات موجزة**: أصوات نقية متعددة (الشيخ مشاري راشد العفاسي، الشيخ عبد الباسط عبد الصمد، الأذان المكي، أو تكبيرات سريعة مناسبة لبيئات العمل).
- **دعاء ما بعد الأذان** صوتياً ومقروءاً.
- **بوصلة اتجاه القبلة** الدقيقة حسب إحداثيات موقعك.

### 2. 💼 إدارة مهام العمل مع التذكير الصوتي الذكي
- **تنبيهات صوتية عربية فصيحة (TTS)**: ينطق النظام عنوان المهمة وتفاصيلها ودرجة أهميتها عند حلول وقتها.
- **إمكانية ربط ملف صوتي مخصص (MP3/WAV) أو تسجيل صوتي مباشر بالمايكروفون** لكل مهمة يعمل تلقائياً عند وقت التنبيه.
- **كاشف التعارض الذكي**: يفحص مواعيد المهام والاجتماعات ويحذرك فوراً إذا كان الموعد قريباً من أي صلاة (خلال 15 دقيقة) لتنظيم وقتك ببركة.
- **درجات أولوية متعددة**: عاجل جداً، مرتفعة، متوسطة، منخفضة مع نغمات تنبيهية مميزة.
- **خاصية الغفوة (Snooze)**: تأجيل التنبيه 5، 10، أو 15 دقيقة بضغطة زر.
- **احتفال بإنجاز المهام**: تأثيرات بصرية وصوتية محفزة عند إكمال المهام.

### 3. 🎬 المشغّل المجدول للوسائط (فيديو وصوت) (جديد ✨)
- **رفع مقاطع الفيديو** (`MP4`, `WebM`, `MOV`, `MKV`) مع توليد صور مصغرة تلقائية (Thumbnails) وحساب المدة بدقة.
- **رفع الملفات الصوتية** (`MP3`, `WAV`, `M4A`, `OGG`, `AAC`) والتسجيل المباشر بالمايكروفون.
- **شاشة عرض فيديو منبثقة تفاعلية**: عند حلول موعد الفيديو المجدول، تنبثق شاشة عرض سينمائية بدقة عالية مع تشغيل تلقائي وأزرار للتحكم والشاشة الكاملة.
- **تخزين آمن في IndexedDB**: تخزين محلي غير محدود للملفات الكبيرة على جهازك دون استهلاك إنترنت.
- **جدولة دقيقة بالوقت والتاريخ**: حدد موعد تشغيل الفيديو أو الصوت تلقائياً (مرة واحدة، يومياً، أسبوعياً، أو أيام العمل).
- **أذان مخصص من اختيارك**: إمكانية رفع ملف أذان MP3 للشيخ المفضل لديك وتفعيله كأذان رئيسي للصلوات.

### 4. ⏱️ مؤقت التركيز والإنجاز (بومودورو الذكي)
- جلسات عمل 25 دقيقة واستراحات 5 أو 15 دقيقة.
- **توجيه صوتي عربي**: إعلان بداية ونهاية جلسات التركيز لتشجيعك وتذكيرك بشرب الماء.
- **تزامن مع الصلاة**: إيقاف مؤقت تلقائي لجلسات العمل عند دخول وقت الأذان.

### 4. 📿 الأذكار والسبحة الإلكترونية
- **سبحة إلكترونية تفاعلية** مع أصوات نقر هادئة واهتزاز عند بلوغ الهدف (33 أو 100).
- أذكار العمل والتوفيق والبركة في الرزق.
- أذكار الصباح والمساء وأذكار ما بعد الصلاة مع زر استماع صوتي لكل ذكر.

### 5. 🖥️ إشعارات سطح المكتب (Windows Notifications)
- إشعارات منبثقة على سطح المكتب تعمل حتى في حال تصغير المتصفح.

## 🚀 طريقة التشغيل السريعة

1. افتح موجه الأوامر (PowerShell أو Terminal) في مجلد المشروع:
   ```bash
   cd "C:\Users\Administrator\.gemini\antigravity\scratch\smart-reminder-system"
   ```

2. شغل خادم التطوير:
   ```bash
   npm run dev
   ```

3. افتح الرابط في المتصفح:
   ```
   http://localhost:5173
   ```
   أو قم بالضغط المزدوج على ملف `run.bat`.
